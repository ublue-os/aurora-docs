# Sources de documentation externes pertinentes

Si vous ne trouvez pas ce que vous cherchez, la documentation de nos projets apparentés ou la documentation officielle de Fedora Kinoite traite peut-être du sujet qui vous intéresse. Vous les trouverez ici :

- [**Documentation de Fedora Kinoite**](https://docs.fedoraproject.org/en-US/fedora-kinoite/) : Aurora n’existerait pas sans Fedora Kinoite ; il s’agit donc de la meilleure référence pour les informations techniques.
- [**Documentation de Bluefin**](https://docs.projectbluefin.io/) : des informations pertinentes pour Aurora, à l’exception des ajustements propres à GNOME.
- [**Documentation de Bazzite**](https://docs.bazzite.gg) : certaines informations ne s’appliquent pas à Aurora, mais la plupart peuvent constituer une référence utile pour les sujets sur lesquels vous avez des doutes.

Documentation des projets en amont :

- [**Documentation de Bootc**](https://bootc-dev.github.io/bootc/)
- [**Documentation de rpm-ostree**](https://coreos.github.io/rpm-ostree/)
