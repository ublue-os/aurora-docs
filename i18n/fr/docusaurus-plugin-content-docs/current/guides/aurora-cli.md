description: Un rapide tutoriel sur Aurora CLI
---

Aurora CLI est un environnement en ligne de commande conteneurisé et facultatif qui inclut de nombreux outils modernes pour le terminal. Vous pouvez l’activer ou le désactiver selon votre usage et vos préférences en matière de ligne de commande.

Pour activer cet environnement en ligne de commande, exécutez `ujust aurora-cli`. Nous ajouterons d’autres utilitaires et affinerons cet environnement au fil du temps.

Relancez la commande `ujust` ci-dessus pour obtenir les derniers outils ajoutés lors d’une mise à jour.

## Outils inclus {#included-tools}

Les outils en ligne de commande suivants sont inclus dans Aurora CLI :

| Nom                                                                   | Description                                                                                                   |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |

| [bash-preexec](https://formulae.brew.sh/formula/bash-preexec)         | Fonctions preexec et precmd pour Bash (comme dans Zsh)                                                        |
| [bbrew](https://formulae.brew.sh/formula/valkyrie00/bbrew/bbrew)      | Surcouche de Brew bundle pour une meilleure gestion des dépendances                                           |
| [carapace](https://formulae.brew.sh/formula/carapace)                 | Cadriciel de complétion pour plusieurs shells                                                                 |
| [chezmoi](https://formulae.brew.sh/formula/chezmoi)                   | Gestion sécurisée de vos fichiers de configuration personnels sur plusieurs machines                          |
| [direnv](https://formulae.brew.sh/formula/direnv)                     | Chargement et déchargement de variables d’environnement selon le répertoire courant                           |
| [dysk](https://formulae.brew.sh/formula/dysk)                         | Informations sur vos disques montés                                                                           |
| [eza](https://formulae.brew.sh/formula/eza)                           | Remplaçant moderne et maintenu de ls                                                                          |
| [fd](https://formulae.brew.sh/formula/fd)                             | Alternative simple, rapide et conviviale à find                                                               |
| [gh](https://formulae.brew.sh/formula/gh)                             | Outil en ligne de commande de GitHub                                                                          |
| [glab](https://formulae.brew.sh/formula/glab)                         | Outil en ligne de commande de GitLab                                                                          |
