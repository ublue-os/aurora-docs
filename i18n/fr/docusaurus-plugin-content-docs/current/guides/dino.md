---
title: Et si j'avais des dinosaures avec ça ?
description: Fonds d'écran Bluefin sur Aurora
---

Pour définir les [fonds d'écran Bluefin](https://projectbluefin.io) sur votre machine Aurora, procédez ainsi :

```
ujust toggle-dinosaurs
```

Si vous vivez dans l'hémisphère sud :

```
ujust toggle-dinosaurs south
```

Merci à [grandpares](https://github.com/grandpares/plasma-bluefin-wallpaper) !
